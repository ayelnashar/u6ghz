u6sim v1.0: interactive implementation of the framework in “Interference and Coexistence in the Upper 6 GHz Band” (IEEE OJ-COMS). Same models, constants and random-number generator as the accompanying Python notebooks (numpy PCG64, seed 42, 400 snapshots), so the reference case reproduces the published values. Models: ITU-R P.452-16 (smooth earth, 20% time, Dubai radio climate) · P.2108 · P.2109 · P.1238 · M.2101 composite pattern (exact) · F.1245 | Criteria: IMT I/N −6 dB · GSO FSS −10.5 dB/20% · FS −10 dB/20%.
Note: deployment values (ISD, EIRP, FS geometry) are editable placeholders; replace with operator planning data for regulator-facing runs. The Fixed-Service margins rest on the P.2108 clutter loss at each base station; without it no evaluated mitigation protects a co-channel link aimed at the cluster.

IMT ↔ Wi-Fi coexistence matrix

Wi-Fi downlink throughput (Mbit/s) as a victim of the mobile network, by mobile traffic state (Engine B). The first row uses the operator block and Wi-Fi channel selected in the sidebar. The trial rows are fixed: they use the 7050/80 MHz trial carrier (7010–7090 MHz) and are compared with the BT/Nokia Adastral Park measurements. 193/160 and 221/160 are the same 160 MHz channel (6905–7065 MHz) with different primary channels. The base station emits across the whole block; the active handset transmits on one NR carrier of up to 100 MHz at the block edge nearest the Wi-Fi channel. When the primary 20 MHz channel is clear, the access point may fall back to a narrower clear sub-channel; the "mode" column shows when that gives the better result.

Terminal–Wi-Fi coupling

Local coupling between an outdoor IMT terminal and an indoor Wi-Fi access point (building entry included), in both directions, at the separation set in the sidebar. The handheld uses the same antenna in both directions (−4 dBi with 4 dB body loss, 26 dBm conducted, 18 dBm EIRP); the rooftop CPE has a 23 dBi array and a 31 dBm EIRP cap. The terminal transmits on one NR carrier of up to 100 MHz; the access point has 23 dBm EIRP and 6 dBi receive gain. Interference into the serving base-station receiver is not modelled.

u6sim v1.1: browser implementation of the framework in A. Elnashar, M. A. El-saidny and S. Muhaidat, “Interference and Coexistence in the Upper 6 GHz Band: A Practical Framework for 5G-Advanced and 6G Giga-MIMO Deployment,” IEEE Open Journal of the Communications Society, 2026. It uses the same models, constants and random-number generator as the v1.1 Python notebook (numpy PCG64), so both give the same results for the same inputs.
Models: 3GPP TR 38.901 UMa NLOS (floored at free space) · ITU-R P.452-16 (smooth earth, 20% time, Dubai climate) · P.2108-1 §3.2 · P.2109 · P.1238 · M.2101 composite pattern · F.1245-3 · bandwidth-integrated ACIR coupling · Resolution 220 (WRC-23) mask. Criteria: IMT I/N −6 dB · GSO FSS −10.5 dB / 20% · FS −10 dB / 20% (study criteria).
Note: deployment values (ISD, EIRP, Fixed-Service geometry) are representative placeholders; replace them with planning and incumbent data for any decision. Without clutter loss at the base stations, no evaluated mitigation protects a co-channel Fixed-Service link aimed at the cluster.
